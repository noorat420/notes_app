# 📝 Scribbly – Simple Notes App

Scribbly is a clean and minimal note-taking web application built to help users capture ideas, plan their day, and organize thoughts effortlessly. Designed with a focus on simplicity, readability, and a pleasant writing experience.

---

## 🚀 Features

- ✍️ Create notes with title and content  
- 📄 View all notes in a clean layout  
- 🧹 Distraction-free writing experience  
- 📱 Fully responsive (mobile & desktop)  
- ⚡ Fast and lightweight  

---

## 🛠️ Tech Stack

**Frontend**
- Next.js (App Router)
- React
- CSS (Custom global styles)
- Bootstrap utilities

**Backend**
- Next.js API Routes

---

## 📂 Project Structure

```
app/
 ├─ page.js            # Homepage
 ├─ notes/

 │   └─ add/
 │       └─ page.js    # Add new note
 ├─ api/
 │   └─ notes/
 │       └─ route.js   # Notes API
public/
globals.css
```

## ⚙️ Installation & Setup

1. Clone the repository
```bash
git clone https://github.com/noorat420/scribbly_notes_app.git
```

2. Navigate to the project folder
```bash
cd scribbly-notes-app
```

3. Install dependencies
```bash
npm install
```

4. Run the development server
```bash
npm run dev
```

5. Open in browser
```
http://localhost:3000
```
